# blog.orb.gay
blog.orb.gay is the evil twin of orb.gay. Why? Because it has a lot of javascript used instead of something like HTMX. There is an advantage to this: markdown files won't need to be parsed into an external server, and be reparsed into a HTMX fragment, it's all rendered on the browser side.

Rendering full markdown for this blog means that I can easily write in Obsidian or Apostrophe, and all the pretty rendering will show up on the blog website too. This can be handy if I'm documenting code, or try to put a concise table LLM style.

It's fun. And the best part? It's mostly written by me, with zero knowledge of JavaScript. Dear god, what am I doing?
